# Produto — Intranet Corporativa

## Visão

A solução é composta por:

1. uma intranet para colaboradores;
2. um CMS administrativo;
3. uma API compartilhada.

O objetivo é fornecer uma experiência minimalista para publicação de conteúdo
e acesso a serviços corporativos.

## Objetivos principais

- publicar notícias;
- gerenciar sistemas e serviços;
- manter páginas institucionais;
- publicar banners;
- compor a home;
- administrar usuários e permissões;
- evoluir posteriormente para notificações, busca e favoritos.

## MVP

### CMS

- dashboard básico;
- notícias;
- categorias;
- sistemas;
- páginas institucionais;
- banners;
- usuários e perfis básicos.

### Intranet

- home;
- notícias;
- sistemas;
- páginas institucionais.

### Infraestrutura

- autenticação;
- autorização básica;
- PostgreSQL;
- storage de arquivos;
- logs;
- auditoria mínima.

## Fora do primeiro MVP

- workflow complexo de aprovação;
- agenda;
- favoritos;
- busca global;
- editor de menus;
- analytics;
- chat;
- rede social corporativa;
- aplicativo mobile nativo.

## Princípios

- simplicidade;
- consistência;
- configurabilidade;
- auditabilidade;
- reutilização;
- separação clara entre CMS, Intranet e API.
